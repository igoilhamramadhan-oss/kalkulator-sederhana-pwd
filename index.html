Hitung Dua Angka

Masukkan dua angka, lalu pilih operasi.

Hasil: 0

Jumlah Perhitungan: 0

Sifat Hasil: -

Panduan Pengguna

  1. Masukkan angka pertama.
  2. Masukkan angka kedua.
  3. Pilih salah satu operasi: tambah, kurang, kali, bagi.
  4. Hasil perhitungan akan ditampilkan pada bagian hasil.
  5. Statistik jumlah perhitungan akan bertambah setiap kali perhitungan berhasil.
  6. Gunakan tombol hapus untuk mengosongkan kedua input.
  7. Gunakan tombol Tampilkan Panduan untuk melihat atau menyembunyikan panduan.
